# *Part 6 - System Administration Roles*

## Helpdesk Technician
#### Responsibilities
A Helpdesk Technician provides first-level technical assistance to company employees. Responsibilities include troubleshooting computer problems, installing applications, resolving login issues, setting up user workstations, diagnosing printer problems, providing remote support and escalating complex problems to senior IT personnel.
### Skills
A Helpdesk Technician should understand Windows operating systems, basic networking, hardware troubleshooting, software installation, user-account administration and customer service. Strong communication and documentation skills are also important because the technician regularly communicates with non-technical employees.
### Common Tools
- Ticketing systems
- AnyDesk
- Remote Desktop
- Microsoft 365 Admin Center
- PowerShell
- Active Directory
- Windows Event Viewer
- Ping and IPConfig
- Hardware diagnostic utilities
### Certifications
- CompTIA A+
- Cisco Certified Support Technician (CCST)
- Microsoft Fundamentals certifications

## Network Administrator
### Responsibilities

The Network Administrator designs, configures, maintains and troubleshoots organizational networks. Responsibilities include configuring routers, switches, firewalls, VLANs, wireless networks, IP addresses, VPN connections and network security policies.

The Network Administrator also monitors network performance and resolves connectivity problems.

### Skills

- TCP/IP
- IPv4 and IPv6
- Subnetting
- VLAN configuration
- Routing and switching
- DHCP
- DNS
- VPN configuration
- Firewall management
- Network security
- Wireless networking
- Network troubleshooting

### Common Tools

- Wireshark
- PuTTY / SSH
- Cisco IOS or equivalent network operating systems
- Ping
- Traceroute
- Nmap
- Network monitoring software
- Firewall management platforms

### Certifications

- A common certification is Cisco Certified Network Associate (CCNA).
- Cisco states that its current CCNA covers networking fundamentals, network access, IP connectivity, IP services, security fundamentals, automation and programmability.

## Cloud Administrator
### Responsibilities

A Cloud Administrator manages computing resources hosted through platforms such as Microsoft Azure, Amazon Web Services or Google Cloud.

Responsibilities may include managing virtual machines, cloud storage, networking, identities, backups, access permissions, monitoring and cloud security.

### Skills

- Cloud computing fundamentals
- Identity and Access Management
- Virtual machines
- Cloud networking
- Storage services
- Backup and disaster recovery
- Security groups and firewalls
- Automation
- Monitoring
- Cost management

### Common Tools

- Microsoft Azure Portal
- AWS Management Console
- Azure CLI
- AWS CLI
- PowerShell
- Terraform
- Cloud monitoring platforms
- Git

### Certifications

- Microsoft Certified: Azure Fundamentals
- Microsoft Certified: Azure Administrator Associate
- AWS Certified Cloud Practitioner
- AWS Certified Solutions Architect – Associate
- Microsoft's current Azure Administrator Associate credential focuses on configuring, managing, securing and administering Azure resources. AWS also currently provides foundational Cloud Practitioner and Solutions Architect Associate credentials.
---
The Helpdesk Technician, Network Administrator, Linux System Administrator, and Cloud Administrator work collaboratively to maintain a stable, secure, and efficient IT environment.
The Helpdesk Technician serves as the first point of contact for users and handles common hardware, software, account, and workstation concerns.
Network-related problems are managed by the Network Administrator, server and Linux-based services are handled by the Linux System Administrator, and cloud-hosted systems and resources are maintained by the Cloud Administrator.
Each role has a specific area of responsibility, effective IT operations depend on strong coordination among them because business applications often rely on interconnected networks, servers, endpoints, security controls, and cloud services.
