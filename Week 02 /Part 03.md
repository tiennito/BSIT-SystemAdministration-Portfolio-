## 3.2 Software Justification

**Windows 11 Pro:** will serve as the standard client operating system so users have a consistent, manageable environment.

**Ubuntu Server 26.04 LTS:** will be installed on the company's primary server because it provides a stable Linux environment suitable for web services, internal development systems, containers, monitoring systems and other server workloads.

**Microsoft Office/Microsoft 365:** is required by HR, Finance, Sales and management for documents, spreadsheets, reports, presentations and communication.

**VS Code, Git and GitHub Desktop:** are particularly important to the IT Department because the company develops software and requires source-code management.

**VirtualBox:** allows the IT team to create isolated virtual machines for learning, testing operating systems and testing configuration changes without affecting production equipment.

**Google Chrome:** is needed for general internet access and for testing web applications.

**Microsoft Defender** provides baseline endpoint security for Windows systems.

**AnyDesk:** allows authorized IT personnel to provide remote technical support.

**7-Zip:** provides file compression and decompression for common archive formats.
